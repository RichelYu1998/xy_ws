# ==================== 版本锁定说明 ====================
#
# 📌 重要提示:
# 1. 生产环境请使用精确版本号 (==) 而非范围约束 (>=)
# 2. 定期运行 `pip-audit` 检查已知CVE漏洞
# 3. 使用 `pip-compile` 从 requirements.in 生成锁定文件
# 4. Playwright版本需定期升级以修复浏览器漏洞
#
# 🔒 安全要求:
# - cryptography >= 42.0 (修复多个CVE)
# - Pillow >= 10.0 (修复图像处理RCE漏洞)
# - requests >= 2.32.0 (修复Header注入漏洞)
# - urllib3 >= 2.0 (修复Cookie注入漏洞)
# - playwright >= 1.45 (修复Chromium漏洞利用)
#
# 🚀 推荐命令:
# pip install -r requirements.txt          # 安装所有依赖
# pip-audit -r requirements.txt            # 安全审计
# safety check -r requirements.txt         # CVE扫描
# bandit -r .                               # 静态代码分析
# playwright install chromium               # 安装浏览器引擎
