# 图片/视频保存目录 —— 脱敏示例（本文件仅为格式说明，不参与运行）
# 实际生效的文件是同目录下的 download_dir.txt
#
# 规则：
#   1. 一行一个目录，只取第一条有效路径，前后空白会被自动忽略
#   2. # 开头为注释，行尾 # 之后的内容也会被忽略
#   3. 支持 ~ 展开（macOS / Linux），页面保存时会自动把家目录缩写成 ~
#      所以本文件里不会出现真实用户名，可直接截图 / 分享
#   4. 目录不存在会自动创建；不可写时页面会提示换一个目录
#   5. 每个商品在其下单独建一个子文件夹，文件夹名取「商品描述」，
#      例如 16 Pro Max 白色256G 电池92% 成色九九新/01.jpg
#      描述相同时不同商品会自动追加序号区分（-2、-3 …）
#
# macOS / Linux 示例（把 <用户名> 换成自己的，或直接用 ~）：
# ~/Downloads/微购
# /Users/<用户名>/Downloads/微购相册
#
# Windows 示例（注意用正斜杠或双反斜杠，不要用单反斜杠）：
# D:/图片/微购相册
# D:\\图片\\微购相册
#
# 修改后保存即生效（页面「保存位置 → 更改」也可直接改）
