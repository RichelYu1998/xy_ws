# 商品品类与文件夹命名关键词示例（复制为 folder_naming.txt 后修改，热读取，改完即生效）
#
# 四大类：手机 / 笔记本 / 平板 / 手表（含智能穿戴），其余统一归入「其他」
# 目录结构：保存目录/品类/品牌/商品文件夹名
#   手机/华为/华为Nova 12活力版 电池97%
#   笔记本/联想/联想小新Air15 2021款
#   平板/苹果/iPad Pro 11英寸第四代
#   手表/苹果/Apple Watch SE3 40mm
#   其他/大疆/大疆Pocket3
# 品牌关键词见同目录 brands.example.txt
#
# 命名规则：
#   手机（iPhone / 华为 / 小米 / OPPO / vivo / 荣耀 / 三星…）→ 「型号 + 电池」
#       16 Pro Max 白色256G 电池92% 成色九九新  →  16 Pro Max 电池92%
#   笔记本 → 只保留「型号」
#       联想小新Air15 2021款 i5-1155G7 16G 512G固态  →  联想小新Air15 2021款
#   平板 → 只保留「型号」
#       iPad Pro 11英寸第四代 日版256G深空灰 电池100%  →  iPad Pro 11英寸第四代
#   手表 → 只保留「型号」
#       Apple Watch SE3 40mm 电池容量100%  →  Apple Watch SE3 40mm
#   其他 → 只保留「型号」
#       Apple HomePod mini 蓝色二代 苹果智能音箱  →  Apple HomePod mini
#
# 型号 = 商品描述里第一个规格词之前的内容
# 关键词分节，一行一个，不区分大小写，默认已内置常见词，这里只写要追加的
# 品类判定顺序：手表 → 平板 → 笔记本 → 其他 → 手机（先具体后笼统）

[颜色]
# 颜色词：出现即视为型号结束（型号保留在颜色之前）
# 默认已内置 白色/黑色/蓝色/金色/深空灰/远峰蓝… 等

[规格]
# 规格词：出现即视为型号结束（成色、电池、保修、拆修、配置、CPU 等）
# 默认已内置 电池/成色/外观/边框/屏幕/换过/国行/港版/内存/硬盘/显卡… 等

[手机品牌]
# 手机品牌 / 手机型号标识，命中即按手机处理（会带上电池）
# 默认已内置 iphone/苹果/华为/荣耀/小米/红米/oppo/vivo/一加/三星/promax/pro/plus… 等

[非手机]
# 非手机品类，命中即不再算手机（优先级高于「手机品牌」，如「iPhone 原装手机壳」）
# 默认已内置 watch/ipad/平板/macbook/笔记本/音箱/耳机/相机/配件… 等

[笔记本]
# 笔记本大类关键词，命中即归「笔记本」并只保留型号
# 默认已内置 macbook/笔记本/游戏本/拯救者/小新/机械革命/thinkpad/天选/rog… 等

[平板]
# 平板大类关键词，命中即归「平板」并只保留型号
# 默认已内置 ipad/平板/matepad/pad/tab/y700… 等

[手表]
# 手表大类关键词，命中即归「手表」（含智能穿戴：手环 / 腕表）并只保留型号
# 默认已内置 watch/手表/腕表/手环/iwatch/band… 等

[其他]
# 其余智能设备关键词：不属于上面四类的都会落到「其他」并只保留型号
# 默认已内置 音箱/耳机/airpods/homepod/相机/大疆/键盘/鼠标/配件/显示器/投影… 等
