# 清理接口允许目录白名单 —— 脱敏示例（本文件仅为格式说明，不参与运行）
# 实际生效的文件是同目录下的 clean_allowed_roots.txt
#
# 规则：
#   1. 一行一个目录，前后空白会被自动忽略
#   2. # 开头为注释，行尾 # 之后的内容也会被忽略
#   3. 支持 ~ 展开（macOS / Linux）
#   4. 项目目录本身始终允许，无需在此重复填写
#   5. 也可以用环境变量 CLEAN_ALLOWED_ROOTS 追加，多个目录用系统分隔符分隔
#      macOS / Linux：冒号分隔   Windows：分号分隔
#   6. 白名单之外的目录一律拒绝，/、/etc、上级目录、../ 逃逸全部拦截
#
# macOS / Linux 示例（把 <用户名> 和目录名换成自己的）：
# /Users/<用户名>/Downloads/相册导出
# ~/Downloads/微购相册
#
# Windows 示例（注意用正斜杠或双反斜杠，不要用单反斜杠）：
# D:/图片/微购相册
# D:\\图片\\微购相册
#
# 修改后需重启服务生效（白名单在进程内只读一次并缓存）
