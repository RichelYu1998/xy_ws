功能特性

微购相册商品采集

基于 Playwright 登录 www.szwego.com 抓取商品详情、货号、备注与价格

货号对比

调用 /api/sku/compare 将采集结果与库存货号清单逐条比对，输出缺失与重复

Excel 平台对比

调用 /api/sku/compare/excel 按平台（闲鱼 / 小红书）解析 Excel 售价并与 JSON 数据比对

每日利润报表

调用 /api/daily-profit 按日统计成交价、手续费、成本与利润率

文件清理工具

调用 /api/clean/list、/api/clean/group、/api/clean/time、/api/clean/png 按条件清理冗余文件

隧道共享

调用 /api/tunnel/start 启动内网穿透，把本地服务共享给外网访问

商品数据查询

调用 /api/products、/api/product、/api/product/search 浏览与检索已采集的商品

安全合规检查

调用 /api/security/check 与 /api/security/audit 执行攻防检查与依赖漏洞审计

邮件通知

调用 /api/email/config 与 /api/email/test 配置并验证 SMTP 通知
